# Book Management System (CLI)

This project is a command-line (CLI) application built in Python for managing a collection of books.

The system stores and processes information about authors, book titles, publication years, and sales figures.

---

## 📌 Features

- Add new books to the database
- Delete existing books
- Update book sales figures
- Search for books by author
- Identify the oldest book(s)
- Save all updates back to file

---

## 🛠 Technologies Used

- Python
- File handling (read/write operations)
- Lists and data processing
- Menu-driven CLI interface

---

## 📂 Files

- `bookAuthors.py` – main application
- `books.txt` – data storage file

---

## ▶️ How to Run

1. Ensure `books.txt` exists with data in the format:
   Author, Title, Year, Sales

2. Run the script:

```bash
python bookAuthors.py
